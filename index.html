A linear voltage surrogate

Select a bus, then press D for a load pulse or E to change forecast reliability. Press Space to run or pause. The state is voltage deviation from nominal. Each bus has an equivalent control input. Tree distances define a dense linear coupling model.

xt+1 = Axt + ut + wt

Values use per unit coordinates and abstract control intervals. This illustration does not calculate AC power flow, actuator saturation, or hard voltage limits.
