About this demoO PredSLS · Shared online adaptation

A linear voltage surrogate

Choose a bus and click Add disturbance, or press D, to inject an unexpected load pulse. The experiment starts immediately. Press E to change forecast reliability and Space to pause or resume. The state is voltage deviation from nominal. Each bus has an equivalent control input. Tree distances define a dense linear coupling model.

xt+1 = Axt + ut + wt

Values use per unit coordinates and abstract control intervals. This illustration does not calculate AC power flow, actuator saturation, or hard voltage limits.

Shared prediction adaptation

A shared matrix calibrates forecasts using the latest 60 revealed samples. This reduced ridge loss illustrates online learning and differs from the full manuscript algorithm and its theoretical guarantees.

ut = Kxt − HGtŵt

The matrix shows three recommended remote sources per receiver. Rows are receivers and columns are sources. Teal cells mark added links and amber outlines mark removed links since the reference step. Add a disturbance or choose Set reference to begin a new comparison. Arrow width encodes prediction score. Node halos indicate voltage deviation. The physical feeder and deployed communication stay fixed. The plots accumulate quadratic stage cost. They do not report formal regret. Frozen fitting measures convergence to a fixed numerical solution. Online data and source rankings can continue to change.
