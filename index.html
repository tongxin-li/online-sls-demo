Synthetic benchmark dynamics

xₜ₊₁ = Axₜ + uₜ + wₜ   ·   yₜ = 1 + xₜ

A = 0.4I + 0.58D−½WD−½, where Wᵢⱼ = exp(−dᵢⱼ / 2) for different buses, Wᵢᵢ = 0, and D contains row sums of W. This reproduces the paper’s synthetic communication benchmark. A is based on graph distance, not electrical impedance. Every node has an unconstrained direct input B = I. There is no power flow equation, power balance, fixed slack bus or inverter capability model. The displayed value y is an abstract normalized state, not a computed physical voltage.

The stage cost is cₜ = 35‖xₜ‖² + 0.08‖uₜ‖². An unexpected pulse enters xₜ₊₁, so its state cost appears at the following sample. The plots preserve that timing.

Equipment artwork gives different decay profiles to abstract additive disturbances. A click does not represent a specified load change in kW or an inverter response in kvar. Repeated clicks add disturbances, including several at the same paused step. States are never clipped. The target band is illustrative.

What is being learned

This is a shared matrix experimental variant. A fixed LQR feedback gain regulates the abstract state. A learned matrix G adjusts five previewed disturbance samples, using the latest 60 revealed samples and starting at step 30. The displayed links rank prediction gains. They are recommendations only. The illustrated tree stays fixed and the dense controller continues to use all sources.

Forecast → control → observe wₜ → fit G → next control

Live data keeps changing, so gain changes need not decay monotonically. Freeze data holds the plant and fits the same ridge objective repeatedly, showing error relative to its exact minimizer.

Algorithm 1 in the paper

Φ̂(t+1) = ΠFd[Φ̂(t) − η∇h̃t−d(Φ̂(t−d))]

The full algorithm updates completed FIR response windows with a delayed gradient and projection. Its theorem concerns a fixed completed prefix. This browser experiment uses a restricted shared gain and a declared ridge fit, rather than reproducing that full update or its convergence guarantee.
