Voltage dynamics

xₜ₊₁ = Axₜ + uₜ + wₜ   ·   vₜ = 1 + xₜ

A = 0.4I + 0.58D−½WD−½, where Wᵢⱼ = exp(−dᵢⱼ / 2) for different buses, Wᵢᵢ = 0, and D contains row sums of W. This is the paper’s coupled communication scenario. All buses have the same actuation model B = I.

The stage cost is cₜ = 35‖xₜ‖² + 0.08‖uₜ‖². An unexpected pulse enters xₜ₊₁, so its state cost appears at the following sample. The plots preserve that timing.

Home load surges, solar cloud cover, battery output losses and feeder disturbances have different decay durations. Repeated clicks add disturbances, including several at the same paused step. Voltage values are never clipped. The target band is illustrative, not a hard constraint.

What is being learned

This is a shared matrix experimental variant. A fixed LQR feedback gain regulates voltage. A learned matrix G adjusts five previewed disturbance samples, using the latest 60 revealed samples and starting at step 30. The displayed links rank prediction gains. They are recommendations only. The physical feeder stays fixed and the dense controller continues to use all sources.

Forecast → control → observe wₜ → fit G → next control

Live data keeps changing, so gain changes need not decay monotonically. Freeze data holds the plant and fits the same ridge objective repeatedly, showing error relative to its exact minimizer.

The full algorithm updates completed FIR response windows with a delayed gradient and projection. Its theorem concerns a fixed completed prefix. This browser experiment uses a restricted shared gain and a declared ridge fit, rather than reproducing that full update or its convergence guarantee.
