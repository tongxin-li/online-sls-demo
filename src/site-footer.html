A linear voltage surrogate

Choose a pulse strength and click a bus to inject an unexpected load disturbance. The button and D shortcut apply the same pulse to the selected bus. The default playback is one control step per second. Press E to change forecast reliability and Space to pause or resume. The state is voltage deviation from nominal. Each bus has an equivalent control input. Tree distances define a dense linear coupling model.

xt+1 = Axt + ut + wt

Values use per unit coordinates and abstract control intervals. This illustration does not calculate AC power flow, actuator saturation, or hard voltage limits.

Shared prediction adaptation

A shared matrix calibrates forecasts using the latest 60 revealed samples. This reduced ridge loss illustrates online learning and differs from the full manuscript algorithm and its theoretical guarantees.

ut = Kxt − HGtŵt

The matrix shows three recommended remote sources per receiver. Rows are receivers and columns are sources. Teal cells mark added links and amber outlines mark removed links since the reference step. Add a disturbance or choose Set reference to begin a new comparison. Arrow width encodes prediction score. Node halos indicate voltage deviation and a ring marks the injected pulse. Visual transitions interpolate the drawing only. The discrete control samples remain unchanged. The physical feeder and deployed communication stay fixed. The instantaneous plot shows the quadratic stage cost xₜᵀQxₜ + uₜᵀRuₜ. The cumulative plot sums these same values. A click advances two real control steps so the pulse is realized and its first affected state cost is visible immediately. Subsequent samples run at the selected speed. The plots do not report formal regret. Frozen fitting measures convergence to a fixed numerical solution. Online data and source rankings can continue to change.
