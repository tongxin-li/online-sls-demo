About the model +

A synthetic 24 bus voltage regulation experiment. Clicking a bus adds an unexpected load pulse that decays over 12 control steps. The controller aims to restore nominal voltage at 1 pu. Equipment icons give the feeder context and share the same linear bus dynamics.

All three controllers face identical disturbances. Shared ridge calibration learns from the latest 60 revealed samples. The matrix shows three recommended remote prediction sources per receiver. The feeder and deployed communication remain fixed.

Cost is 35‖x‖² + 0.08‖u‖². Each attack advances two actual samples so its first affected state cost is visible, then playback continues. Each bus recovers for 12 samples before another attack. The 0.95 to 1.05 pu band is a demo target, not an enforced bound. This reduced model does not simulate AC power flow, actuator limits, or the full manuscript algorithm.
